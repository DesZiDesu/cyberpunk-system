# Phone UI sounds

These five original MP3 uploads were supplied by the repository owner for this extension and published at their request. Filenames are normalized; audio content is unchanged. No ownership or general redistribution license is claimed for the game recordings.

| Local file | Supplied recording | Trigger |
| --- | --- | --- |
| v-phone-ringtone.mp3 | V's Phone (Ringtone) | Incoming call; loops until accept/decline |
| outgoing-call.mp3 | Outgoing Call | Dialing; loops until answer, cancellation or error |
| opening-phone-contacts.mp3 | Opening Phone Contacts | Either party accepts |
| closing-phone-contacts.mp3 | Closing Phone Contacts | Either party hangs up |
| v-phone-new-message.mp3 | V's Phone (New Message) | New mail, direct text or received attachment; not spoken subtitle pages |

Playback observes user volume/mute and pauses when the page is hidden. Mobile browsers can require a user gesture before allowing audio. No microphone, voice synthesis or external audio service is used.
