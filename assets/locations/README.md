# Official location image coverage

This collection is **partial**. The six JPEGs are original public district photographs from [CDPR's Night City tourism site](https://www.nightcity.love/en/), downloaded without upscaling or changing their bytes. Each is **960 × 540**, suitable for the small mobile card but not a full-HD/4K archive. Exact source URLs and SHA-256 hashes are in coverage.json.

| District | Bundled file | Scope |
|---|---|---|
| City Center | city-center.jpg | District reference |
| Watson | watson.jpg | District reference |
| Heywood | heywood.jpg | District reference |
| Westbrook | westbrook.jpg | District reference |
| Santo Domingo | santo-domingo.jpg | District reference |
| Pacifica | pacifica.jpg | District reference |

No exhaustive official interior set was verified. In particular, apartment rooms, bars, clinics, hotels, shops, corporate interiors, quest-only spaces and Dogtown interiors are **not** represented by these six district views. The UI labels references as such and never calls them interior photographs. Unknown districts show a text fallback. Source dimensions and coverage must remain honest when adding images.

Other sources investigated: [official media gallery](https://www.cyberpunk.net/en/cyberpunk-2077), [official apartment DLC announcement](https://www.cyberpunk.net/en/dlc), [community Photo Mode gallery hosted by CDPR](https://www.cyberpunk.net/en/photo-mode-challenge), and [Piggyback](https://maps.piggyback.com/) (advertises over 800 high-resolution Cyberpunk screenshots). A general apartment promo is not proof of a specific interior; community submissions are not automatically official location assets. No Piggyback imagery is bundled.
